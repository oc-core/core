# Sample community archive

A small invented community, shown unpacked so that the files can be read here. A real archive is
each of these folders packed as one ZIP file ([specification](../../community-archive.md), §3).

| Folder | What it is |
|---|---|
| `structure/` | the structure archive: community, policy, governance log, memberships, content manifest |
| `member-m_9c1x6r3w/` | the parcel of one member who confirmed the move |

The community has three memberships. One ended in June and has no parcel. The administrator's
parcel is not included, so the first content item is listed in the content manifest and its body
is absent: this is what an importer sees while a parcel has not arrived. There is no media.

The hashes in both manifests, the chain of the governance log and the link from the parcel to
the structure archive are real and can be recomputed from the files.
